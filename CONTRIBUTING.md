# Contributing to ADAS

Thanks for helping improve the Autonomous Development Automation System.

## Good contribution areas

- orchestration rules
- QA/adversarial strategies
- preflight checks
- resume/checkpoint behavior
- Codex compatibility
- alternative agent backends
- CI integrations
- real-world PoC reports
- documentation

## Before a major workflow change

Open an issue describing:

1. the observed failure or limitation
2. the proposed change
3. expected impact on role ownership
4. expected impact on autonomy/resumability
5. how the change will be validated

## Pull requests

Please keep changes focused and explain:

- which ADAS principle is affected
- whether existing project templates must migrate
- whether Codex-version behavior is involved
- evidence from a real or synthetic run

Do not include secrets, private project data or generated browser profiles.
