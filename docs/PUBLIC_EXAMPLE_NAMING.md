# Public Example Naming

RAD public examples use neutral descriptive project names:

- **Snake** — deterministic grid-movement benchmark
- **Paddle Duel** — local two-player paddle-and-ball benchmark
- **Blockfall** — deterministic falling-block puzzle benchmark

The names describe the benchmark mechanics without presenting the examples as
official implementations of third-party game brands.

Older private/local benchmark artifacts can retain earlier working titles. Those
historical names do not change the technical benchmark scope or validation data.

For public releases, use the neutral names, paths and requirement IDs:

```text
examples/snake/                 FR-SNK-*
examples/paddle-duel/           FR-PDL-*
examples/blockfall/             FR-BLK-*
```
